# JuiceTracker

See how much battery your mouse and headset have left at a glance. JuiceTracker is a portable utility for 64-bit Windows 10 and 11.

**[Download for Windows](https://github.com/saintzdid12/JuiceTracker/releases/download/desktop-widget-v1/WirelessBattery-Dark-Menus.exe)**

1. Exit any older Wireless Battery instance from its menu.
2. Run the downloaded EXE. There is no installer.
3. Click the battery display and open **Options** to choose **Taskbar**, **Desktop widget**, or **Tray icons**. Drag the desktop widget to move it.

The desktop widget shows mouse and headset battery levels side by side. You can set the refresh interval, choose a low-battery threshold, and hide sleeping devices. This build adds support for the Logitech PRO X3 SUPERSTRIKE and a model-specific discharge estimate for the Logitech PRO X Wireless headset.
